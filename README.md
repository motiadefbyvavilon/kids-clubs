# КружокРядом — интегратор детских кружков

Фронтенд-приложение на **Vue 3 + Vite**: сервис для помощи родителям в поиске
и записи детей в кружки по интересам.

## Возможности

1. **Каталог кружков**
   - Поиск по названию, описанию, преподавателю и направлению.
   - Фильтры: категория интересов, формат (онлайн/офлайн), возраст ребёнка,
     бесплатные, только со свободными местами, избранное.
   - Сортировка по названию, цене и возрасту.

2. **Карточка кружка**
   - Полное описание, преподаватель, адрес, цена, свободные места.
   - Расписание занятий по дням недели.
   - Добавление в избранное.

3. **Профили детей**
   - Несколько детей в одном аккаунте: имя, год рождения, интересы.
   - Редактирование и удаление профилей с подтверждением.

4. **Запись в кружок**
   - Выбор ребёнка и запись в один клик.
   - Проверки при записи: возрастной диапазон кружка, наличие свободных мест,
     защита от повторной записи и от пересечений по расписанию с другими кружками ребёнка.
   - Счётчик свободных мест обновляется автоматически.

5. **Расписание недели**
   - Сетка занятий выбранного ребёнка по дням недели.
   - Отмена записи с подтверждением (место освобождается).

Данные хранятся в `localStorage` браузера (демо-режим без бэкенда);
при первом запуске доступны 12 кружков-заглушек и два профиля детей.

## Стек

- Vue 3 (Composition API, `<script setup>`)
- Vite
- Vue Router 4
- Pinia
- Без UI-библиотек: собственные компоненты и дизайн-токены (OKLCH)

## Запуск

```bash
npm install
npm run dev      # дев-сервер
npm run build    # продакшн-сборка в dist/
npm run preview  # просмотр продакшн-сборки
```

## Структура

```
src/
├── main.js
├── App.vue                # каркас: шапка, навигация, тосты
├── router/                # Каталог / Кружок / Мои дети / Расписание
├── stores/clubs.js        # Pinia: кружки, дети, записи, избранное, проверки
├── utils/schedule.js      # дни недели, возраст, цены, плюрализация
├── views/
│   ├── CatalogView.vue     # поиск и фильтры каталога
│   ├── ClubDetailView.vue  # карточка кружка и запись
│   ├── ChildrenView.vue    # профили детей (CRUD)
│   └── ScheduleView.vue    # недельное расписание и отмена записи
└── components/
    ├── ClubCard.vue        # карточка кружка в каталоге
    └── ToastStack.vue      # всплывающие уведомления
```
